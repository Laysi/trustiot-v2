怎麼看

  • 檔案是自足的靜態頁，不連網路：clone 之後用瀏覽器直接打開。GitHub 上點 HTML 只會顯示原始碼。
  • 深色：網址加 ?theme=dark（不加時跟隨系統）；右下角的「設計稿」列也能切換，加 ?bar=0 隱藏這一列。
  • 手機版：*-phone.html 是 390 px 寬的單欄；桌面頁在視窗寬度小於 640 px 時也會變成同一個手機版面。
  • 列表的檢視者模式：list.html?role=viewer，或用右下角的「檢視者模式」。
  • 選單的「平台後台」只有平台管理員看得到：網址加 ?platform=1 看有這個項目的選單。選單裡其他頁面連到其他組設計稿；「設定」沒有對應的設計稿，所以不連。
  • 頁首是共用外框（Laysi/trustiot-v2#1000）：只有 logo、組織切換、「選單」與帳號，沒有常駐導覽列與側欄。
