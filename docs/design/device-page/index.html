設備頁設計稿（Laysi/trustiot-v2#781）：19 種狀態

互動版：device-page.html（右下角切換狀態，調整視窗寬度看手機與桌面版面；寬度小於 640 是手機版面）。說明見 design.md。以下每個連結直接開到該狀態。

  • 正常（數值資料點，最近 24 小時） normal（深色）
  • 互動：放大後指向一個區間（十字線、tooltip／手機的讀值區） hover（深色）
  • 布林資料點 bool（深色）
  • 文字資料點（不畫圖，合併成時段表） text（深色）
  • 載入中（骨架） loading（深色）
  • 離線：資料停滯 stale（深色）
  • 設備沒有讀值 never（深色）
  • 型號沒有資料點 nopoints（深色）
  • 範圍整段超出可查期間（403） outside（深色）
  • 範圍開頭早於可查期間（truncated） truncated（深色）
  • 範圍內沒有讀值 rangeempty（深色）
  • 自訂範圍與驗證錯誤 custom（深色）
  • 歷史載入失敗（局部錯誤） error（深色）
  • 型號載入失敗（只列代號） model-failed（深色）
  • 設備載入失敗（整頁錯誤） pageerror（深色）
  • 找不到設備 notfound（深色）
  • 長內容：長名稱、14 個資料點、長文字值 long（深色）
  • 從 AI 對話的連結進入 fromchat（深色）
  • 深色主題 dark（深色）
