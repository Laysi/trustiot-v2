# 架構決策總表

整體方向是完全去 AWS 化，SaaS 與地端部署跑同一套程式；以下 30 項皆已定案（定案指方案已選定；Istio ambient、Apache AGE 等幾項仍待可行性測試驗證）；broker（Mosquitto）與警報腳本語言（Rhai）已依可行性測試定案。

| 1 | 整體方向 | 完全去 AWS。SaaS 是我們自營的多租戶部署，地端是單租戶部署，兩者同一套程式 | 可提供大型企業純地端部署；只維護一套，避免沒人在用的那套慢慢壞掉 |
