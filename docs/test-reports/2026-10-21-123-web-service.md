# web 服務：深連結、安全標頭與發佈流程的靜態網站

對應 issue：Laysi/trustiot-v2#123（父 issue Laysi/trustiot-v2#25）。本報告涵蓋 `services/web` 與發佈流程的 `[static]`（`scripts/release/static-build.ts`）。SPA 本身（`frontend/`）與入口、chart 的改動在同一張 issue 的其他分支，另有證據；`web` 映像的宣告（`deploy/images/web/image.toml`，`[static] project = "frontend"`）要等那兩個分支合入後才能加，因為 plan 要求專案已存在，發佈也要求 chart 部署它。兩個分支合併進本分支、加上宣告後的重跑在結果第 4 項。

測試日期為 2026-10-21；下方 log 的時間戳記是 UTC。

## 環境

- **受測程式碼**：分支 `feat/123-web-service`，以 main `d77ff65` 為基底；服務是第一個 commit，發佈流程的 `[static]` 與本報告是第二個 commit。結果第 4 項是之後合併 SPA 分支（`frontend/`）與入口、chart 分支，再加上 `web` 映像宣告的版本。
- **執行的地方**：本機開發機（不是部署環境，以下結果與作業系統、硬體無關）。工具都是 `.prototools` 釘選的版本：Rust 1.99.0、Bun 1.4.2、Helm 4.3.0、kubeconform 0.8.0、cargo-deny 0.20.2、gitleaks 8.30.1。
- **網站**：
  - `services/web/tests/fixtures/site/`：測試用的小網站，5 個檔案、694 bytes（`index.html`、`static/B7f3kQ2x.js`、`static/Cq9_Lm-1.css`、`favicon.svg`、`robots.txt`）。
  - 結果第 3 項另外用 `frontend/` 當天開發中的版本（尚未合入 main）建置一次。

## 指令

從 repo 根目錄執行。

```sh
# 1. 單元與程序測試、規則檢查
CARGO_BUILD_JOBS=3 cargo test -p web -p openapi -p repo-check
cargo run -p openapi -- --check
CARGO_BUILD_JOBS=3 cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
cargo deny --locked check
bun install --cwd scripts --frozen-lockfile
bun run --cwd scripts typecheck
bun test scripts/release
bun test scripts/nightly scripts/ci
bun test scripts
bun scripts/ci/check-secret-handling.ts

# 2. 以 fixture 網站啟動服務，再以 curl 逐項請求
TRUSTIOT__ROOT_DIR="$PWD/services/web/tests/fixtures/site" \
TRUSTIOT__HTTP__LISTEN_ADDR=127.0.0.1:18080 TRUSTIOT__HTTP__HEALTH_LISTEN_ADDR=127.0.0.1:18081 \
  cargo run -p web
curl -sS -i 'http://127.0.0.1:18080/devices/42?tab=data'
curl -sS -i http://127.0.0.1:18080/static/B7f3kQ2x.js
curl -sS -i http://127.0.0.1:18080/static/missing.js
curl -sS -i -X POST -H 'content-type: application/json' --data '{}' http://127.0.0.1:18080/
curl -sS -I http://127.0.0.1:18080/static/Cq9_Lm-1.css
curl -sS -i -H 'If-None-Match: W/"f36a71bb8f5ca0235f57058ed1ddc6f3"' http://127.0.0.1:18080/devices/42
curl -sS -i 'http://127.0.0.1:18080/static/..%2Findex.html'
curl -sS -o /dev/null -w '%{http_code} %{content_type}\n' --path-as-is http://127.0.0.1:18080/static/../index.html
curl -sS -i http://127.0.0.1:18081/readyz
# 最後送 SIGTERM 結束服務
```

第 3 項以發佈流程的函式建置 `frontend/` 的一份複本：`buildStaticSites`（`bun install --cwd frontend --frozen-lockfile --ignore-scripts`、`bun run --cwd frontend build`、`bun run --cwd frontend check:dist`，再以 `staticSiteProblems` 檢查），接著以 `copyStaticSite` 放進 build context 的 `www/`，再以 web 執行檔（`TRUSTIOT__ROOT_DIR` 指向那個 `www/`）提供它。
