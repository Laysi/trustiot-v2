## 結果

### 品牌 token

| token | 淺色 | 深色 |
| --- | --- | --- |
| `--brand` | `#a0eed6` | `#a0eed6` |
| `--brand-strong` | `#02614e` | `#a0eed6` |
| `--brand-soft` | `#e0fbf1` | `#0e2d25` |
| `--on-brand` | `#082820` | `#082820` |
| `--on-brand-strong` | `#ffffff` | `#082820` |

`--primary` 與 `--ring` 兩個主題都是 `--brand-strong`，`--primary-foreground` 是 `--on-brand-strong`。品牌 token 用 hex，logo 的薄荷綠才會一字不差；既有的中性色與狀態色維持 oklch。

### 對比

完整表（兩個主題各自每一組，加 logo）在 [contrast.md](data/2026-11-01-929-brand-colors/contrast.md)，由 [contrast.ts](data/2026-11-01-929-brand-colors/contrast.ts) 產生；門檻文字 4.5:1、框線與焦點框與圖表線 3:1。重點：

| 主題 | 配對 | 對比 | 門檻 |
| --- | --- | --- | --- |
| 淺色 | 薄荷綠直接放白底（不採用，所以標誌要放在方塊上） | 1.34 | 3 |
| 淺色 | `--primary-foreground` 在 `--primary`（按鈕文字） | 7.44 | 4.5 |
| 淺色 | 按鈕 hover（`primary/90` 在白底上）的文字 | 5.89 | 4.5 |
| 淺色 | `--primary` 當連結文字，最差的面（`--accent`） | 6.53 | 4.5 |
| 淺色 | 焦點框 `--ring`，最差的面（`--accent`） | 6.53 | 3 |
| 淺色 | `--foreground` 在 `--brand-soft` | 16.24 | 4.5 |
| 淺色 | `--on-brand` 在 `--brand` | 11.76 | 4.5 |
| 深色 | `--primary-foreground` 在 `--primary` | 11.76 | 4.5 |
| 深色 | 按鈕 hover 的文字 | 9.58 | 4.5 |
| 深色 | `--primary` 當連結文字，最差的面（`--accent`） | 10.55 | 4.5 |
| 深色 | 焦點框，最差的面（`--accent`） | 10.55 | 3 |
| 深色 | `--primary` 對背景（圖表線） | 14.29 | 3 |
| 兩者 | logo 的薄荷綠標誌在 `#082820` 方塊上 | 11.76 | 3 |

未改動的配對（`--foreground`、`--muted-foreground`、`--destructive`、`--success`、`--input` 框線）也全部重算，都過。

深色背景對 `--brand-strong` 是 14.29:1；維護者的設計系統記的是 14.32:1，差在他們的背景色略有不同，不影響結論。

### 品牌色與狀態色是否分得開

`--success` 與 `--destructive` 沒有改。

- 深色主題：`--success` 是 OKLab 亮度 L 0.75，`--primary`（薄荷綠）是 0.89，亮度差 0.14，亮度對比 1.57:1；`--destructive` 對 `--primary` 是 2.35:1。亮度和色相都分得開。
- 淺色主題：`--success` L 0.50，`--primary` L 0.44，亮度差只有 0.06（亮度對比 1.32:1），`--destructive` 對 `--primary` 是 1.38:1。**淺色主題裡兩者不能靠亮度分開，只靠色相與彩度，也靠用途不同**：`--success` 只出現在帶文字說明的對勾圖示（登入與設定頁），`--primary` 是實心按鈕、連結與焦點框；沒有任何地方只靠顏色區分兩者。成功色要過 4.5:1 的文字對比，所以不能再調亮，主色的 `#02614e` 是設計系統指定的值，這是兩個限制夾出來的結果。`frontend/README.md` 已寫明規則：不要把兩者放進同一個控制項裡靠顏色區分。

### logo

`public/favicon.svg` 換成真的 TrustIoT logo：九個路徑，單色 `#a0eed6`，畫在 `#082820` 的圓角方塊上（標誌對方塊 11.76:1，方塊對白底 15.73:1）。原檔的編輯器 id 與 `style="fill:..."` 已移除，改用 `fill` 屬性（CSP 與 `check:dist` 不允許 `style` 屬性）。版面的 `Brand` 與瀏覽器分頁圖示是同一個檔案。深色頁面上方塊與背景只有 1.22:1，但標誌本身對方塊是 11.76:1，看得清楚（見截圖）。
