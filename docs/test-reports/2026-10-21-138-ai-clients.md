## 環境

- **受測程式碼**：分支 `feat/138-ai-clients` 的 `crates/ai-clients`。
- **執行的地方**：建置主機（x86_64 Linux），經 check queue 執行；Rust 1.99.0（`rust-toolchain.toml`），`CI=1`。
- **樣本**：取自 Anthropic 與 OpenAI 官方文件的回應與串流（2026-10-21 讀取），每個檔案的來源與「原樣」或「組合」寫在 [crates/ai-clients/tests/fixtures/README.md](../../crates/ai-clients/tests/fixtures/README.md)。沒有供應商的 API key，測試不呼叫供應商；HTTP 層的測試對 loopback 上的腳本化 HTTP/1.1 伺服器送請求。


## 結論

| 驗收條件 | 結果 | 證據 |
| --- | --- | --- |
| 錯誤情境清單寫進 README，並以樣本逐一測試分類 | 通過 | [crates/ai-clients/README.md](../../crates/ai-clients/README.md)「錯誤情境」，每列寫出測試名稱 |
| 一般輸入、快取寫入（5 分鐘與 1 小時）、快取讀取與輸出各自解析正確 | 通過 | `usage_categories_parse_from_recorded_responses`、`stream_usage_is_cumulative_and_ends_as_the_non_streaming_response` |
| thinking（含 signature）與工具呼叫解析再序列化後完全相同 | 通過 | `thinking_blocks_and_tool_calls_round_trip_exactly`、`a_streamed_thinking_and_tool_call_turn_matches_the_non_streaming_one_exactly` |
| Decisions 的 predicate 與 score 回應解析正確，格式不符時回報錯誤 | 通過 | `predicate_and_score_answers_parse_and_fit_their_questions`、`malformed_answers_are_errors` |
| 取消串流後不再讀取 | 通過 | `after_cancel_nothing_more_is_read`（讀取次數不變）、`a_token_cancels_a_stream_waiting_in_another_task`、`requests_over_the_concurrency_limit_are_not_sent`（伺服器看到連線關閉） |
| 超過端點並發上限的請求不送出 | 通過 | `requests_over_the_concurrency_limit_are_not_sent`、`decisions_over_the_concurrency_limit_are_not_sent`（伺服器只收到一個請求） |
| `cargo tree -p ai-clients` 不含 contract（CI 檢查） | 通過 | `tests/no_contract.rs`，`cargo test --workspace` 會跑 |

待測：樣本取自官方文件，不是對真實 API 錄下的回應（沒有供應商 API key）。以真實回應再驗證一次是第二個來源，依 2026-10-21 的驗證分級延後，另開 issue。
