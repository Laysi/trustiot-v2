# 登入與個人設定畫面的 Playwright 自動化（Chromium，2026-11-01）

Laysi/trustiot-v2#945（自 Laysi/trustiot-v2#675 拆出）：把 [2026-10-25 的手動流程](2026-10-25-124-login-settings-ui.md)（登入、租戶、個人設定、登出，以及每次開關 Radix 彈出元件後的 CSP 檢查）寫成 Playwright 測試，對真的身分服務與 `services/web`（正式的 CSP 標頭）執行。測試、執行器與規則在 [frontend/README.md](../../frontend/README.md) 「瀏覽器端對端測試」。這份報告是驗收條件的證據。

## 環境

- **程式碼**：以 `origin/main` 的 `d2e47c2f` 為基底加上這個 issue 的變更（`frontend/e2e/`、`scripts/browser-e2e/`、`@playwright/test` 1.64.1 進 `frontend/package.json` 與 `frontend/bun.lock`、`renovate.json5`、文件）。
- **機器**：建置主機（x86_64 Linux），rootless podman；開發環境（`bun scripts/dev.ts up`：Postgres 含 TLS 與 Apache AGE、ClickHouse、Mosquitto、migration Job、身分服務的簽章金鑰）每次執行都是新的實例，結束時 `purge`。
- **服務**：`identity` 與 `web` 以 `cargo build --locked` 建出，在主機上執行；SPA 是 `bun run --cwd frontend build` 的輸出，由 `services/web` 提供（真的 CSP 標頭）。
- **瀏覽器**：Playwright 1.64.1 的 Chromium，在官方映像 `mcr.microsoft.com/playwright:v1.64.1-noble`（以多架構 manifest 的 digest 釘選，見 `frontend/e2e/image.ts`）裡執行，`--network host`、`--cap-drop ALL`、唯讀掛載測試。英文介面（`en-US`），以 `http://localhost:<埠>` 存取。
- **替代品**：入口（`scripts/browser-e2e/ingress.ts`）與收驗證碼信的 SMTP 收信器（`smtp.ts`）；使用者與 session 由 `control.ts` 以 `identity_owner` 寫入。其餘（身分服務、`services/web`、Postgres）都是產品的程式。
- **日期**：2026-11-01。

### 突變：檢查真的會失敗

在建置主機的副本（不是這個分支）把 `frontend/vite.config.ts` 的 `react-style-singleton` alias 改成永遠對不到，Radix 就會把捲動鎖的規則寫進 `<style>`（`no-style-singleton` 要防的事）。完整執行（[mutation-run.txt](data/2026-11-01-945-browser-e2e/mutation-run.txt)）：17 個測試中 3 個失敗，正好是三個開關彈出元件的測試（租戶選單、帳號選單與確認對話框），每個在第一次打開時失敗，訊息是 `securitypolicyviolation events` 收到 `enforce style-src-elem inline`，另有 console 的 `Applying inline style violates the following Content Security Policy directive 'style-src 'self''`；其餘 14 個通過。還原後（最後一次執行）17 個全過。

## 結論

| 驗收條件 | 結果 |

| Playwright 測試涵蓋範圍第 1 項的流程與四項檢查，並在選定的地方通過 | **通過**：17 個測試，選定的地方是建置主機上的本機指令（見下），紀錄在 [final-run.txt](data/2026-11-01-945-browser-e2e/final-run.txt) |

| 專案規定的檢查都通過 | **通過**：見上表 |

**執行位置的決定**：目前只有 `bun scripts/browser-e2e/run.ts`，沒有 CI 工作。一個要起 Postgres、ClickHouse、Mosquitto、編譯兩個 Rust 服務並拉約 1 GB（壓縮後）映像的 job，在沒有快取時就是 repo 轉回私有之後的常駐重型成本。CI 的選項與建議（自建 runner，Laysi/trustiot-v2#893，就緒後接成依路徑觸發的 job）在 `frontend/README.md`，尚待專案擁有者決定。

**限制與未涵蓋**：

- 只有 Chromium（Playwright 1.64.1 附的版本）；Firefox、WebKit 與時區清單在 Laysi/trustiot-v2#946。
- 入口是替代，不是 Istio；經真實入口的錯誤畫面在 Laysi/trustiot-v2#947；bundle 大小在 Laysi/trustiot-v2#948。
- `up` 的 podman 流程只在 x86_64 Linux 驗證過，arm64 沒有試。
- 2026-10-25 手動流程中「窄螢幕 360 px 沒有橫向捲動」不在這張 issue 的範圍，沒有自動化。
