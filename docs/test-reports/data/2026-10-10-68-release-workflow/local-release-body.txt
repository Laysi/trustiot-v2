## 驗證

以 GitHub OIDC 的 keyless cosign 簽章，簽章身分是這個 tag 上的 release workflow。套件是私有的，先以有讀取權限的帳號 `cosign login ghcr.io`：

```sh
cosign verify 127.0.0.1:5068/laysi/trustiot-v2/release-selftest:0.0.0-rc.1 \
  --certificate-identity 'https://github.com/Laysi/trustiot-v2/.github/workflows/release.yml@refs/tags/v0.0.0-rc.1' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
cosign verify 127.0.0.1:5068/laysi/trustiot-v2/charts/trustiot:0.0.0-rc.1 \
  --certificate-identity 'https://github.com/Laysi/trustiot-v2/.github/workflows/release.yml@refs/tags/v0.0.0-rc.1' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
# SBOM：驗證 attestation 後取出 predicate
cosign verify-attestation --type spdxjson 127.0.0.1:5068/laysi/trustiot-v2/release-selftest:0.0.0-rc.1 \
  --certificate-identity 'https://github.com/Laysi/trustiot-v2/.github/workflows/release.yml@refs/tags/v0.0.0-rc.1' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  | jq -r .payload | base64 -d | jq .predicate
```
