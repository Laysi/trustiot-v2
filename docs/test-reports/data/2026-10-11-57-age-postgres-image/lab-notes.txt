First try, Cluster with spec.imageName (no catalog):
  The Cluster "age" is invalid: spec.imageName: Invalid value: "localhost/trustiot-57/postgres:release-local": invalid version tag
  → CloudNativePG reads the PostgreSQL major from the tag. Release tags are TrustIoT versions, so
    the chart must use an ImageCatalog with `major: 18` (deploy/images/postgres/README.md).

Second try: ImageCatalog postgres-age {major: 18, image: localhost/trustiot-57/postgres:release-local@sha256:cb840e19...}
and Cluster age {instances: 1, imageCatalogRef major 18, imagePullPolicy: Never,
postgresql.shared_preload_libraries: [age], storage 1Gi (k3s local-path)}
  → Cluster in healthy state after the image reference was also tagged by digest in containerd
    (kubelet looks the name@digest reference up as name@digest when pulling is disabled)
(what the pod ran and the AGE queries: lab-cnpg-cluster.txt)
