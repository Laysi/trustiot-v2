## Run 1 (Containerfile of dca7fd6): the build failed in the build stage
time="2026-10-11T21:17:19+08:00" level=warning msg="SHELL is not supported for OCI image format, [/bin/bash -euo pipefail -c] will be ignored. Must use `docker` format"
[2/3] STEP 15/16: RUN pg_server_dev="postgresql-server-dev-18_${PG_PACKAGE_VERSION/+/%2B}_arm64.deb"; ...
/bin/sh: 1: Bad substitution
→ podman 5.8.7 ignores SHELL when it builds an OCI image (release.yml builds with --format oci);
  podman 6.1.3 on the workstation had only warned that SHELL is not persisted and still used it.
  The release runner's podman is not pinned, so a release could have failed the same way.
  Fix: no SHELL; every RUN is POSIX sh starting with `set -eu`; image.test.ts checks both.
